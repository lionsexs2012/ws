# 🌐 WOND — Социальная сеть нового поколения

## 🚀 О проекте

WOND — это современная социальная сеть с реальными аудио- и видеозвонками, созданная как клон VK 1.0, но с добавлением современных технологий.

### ✨ Возможности

- 🔐 **Безопасная аутентификация** — JWT + bcrypt шифрование
- 📧 **Подтверждение email** — отправка кода на почту
- 📰 **Стена** — публикация и удаление постов
- 🤝 **Друзья** — отправка/принятие заявок
- 👥 **Группы** — создание до 100 участников
- 💬 **Мессенджер** — реальное время с уведомлениями
- 📞 **Звонки** — аудио и видео (WebRTC)
- 🟢 **Онлайн-статус** — видимость пользователей
- 📱 **Адаптивный дизайн** — работает на телефонах

## 🛠 Технологии

### Бэкенд
- Node.js + Express
- PostgreSQL (база данных)
- Redis (кеш)
- WebSocket (реальное время)
- JWT + bcrypt (безопасность)
- Nodemailer (email)

### Фронтенд
- HTML5 + CSS3
- Vanilla JS (без фреймворков)
- WebRTC (звонки)
